## Task 2 - Windows Domains 
**Windows Domain** – it’s a group of users and computers under the administration of a given business. An example can be **"github.example.com"**, where users log into any computer using a shared central account such as **“github/jdoe”** rather than local machine accounts. 

**Domain Controller** – Server responsible for authentication and directory services. 

The main advantages of having a configured Windows domain: 
-	**Centralized Identity management** – all users across the network can be confused from Active Directory with minimum effort. 
-	**Managing security policies** – being able to configure security policies directly from Active Directory and apply them to users and computers across the network as needed.
